# FitLife — protótipo

## Arquivos
- `css/style.css` e `responsive.css`: cadastro; `css/paginas.css`: telas já logadas.
- `js/validacoes.js`: CPF, data, telefone e senha; `js/cadastro.js`: cadastro de três etapas.
- `js/dados.js`: Temporario.
- `js/perfil.js`, `informacoes.js`, `treinos.js`: interações de cada página.
